# Next Word Prediction

An LSTM-based Next Word Prediction web application built using Python, TensorFlow and Streamlit.

## Live Demo

[Try the Live Demo](https://sonu-next-word-prediction.streamlit.app/)

## Tech Stack

- Python
- TensorFlow / Keras
- LSTM
- Streamlit
- NumPy
- Pandas

## Features

- Predicts the next word based on user input
- LSTM neural network
- Interactive Streamlit interface
- Trained model integrated into the application
